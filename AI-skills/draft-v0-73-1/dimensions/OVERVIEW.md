# DIMENSIONS - overview and cost axis

```yaml
D0: {name: Emergence,   verb: Discover,   class: external, pct: null, content: raw ideas, materials, questions, file: D0-emergence.md}
D1: {name: Condition,   verb: Register,   class: internal, pct: 0-100, content: FMBOA journal, source of truth, file: D1-condition.md}
D2: {name: Conception,  verb: Articulate, class: internal, pct: 0-100, content: BIOPGE logical contract, file: D2-conception.md}
D3: {name: Incarnation, verb: Fabricate,  class: internal, pct: 0-100, content: substrate + build journal, file: D3-incarnation.md}
D4: {name: Experience,  verb: Track,      class: external, pct: null, content: real-use feedback, file: D4-experience.md}

numbering: cost axis, NOT execution order.
cost: {D0: none, D1: minimal, D2: moderate, D3: high, D4: extreme}
entry_point: arbitrary. exit_point: arbitrary. bypass allowed.
over_engineering: do not run all 5 on a low-complexity System.
external_dims: float permanently, never close, carry no percentage, always null.
absolute_rule: no production without a D0 rich enough to feed a coherent D1.
               a too-vague System produces nothing, not a partial D1.
repair: descending the cost axis. going back is going cheaper, never a failure.
```

Routing: load exactly the `D*.md` file matching the dimension in play. Each is
self-contained. Do not load more than one dimension file per inference unless a
PROPAGATION check (see `draft-concept/PROPAGATION.md`) explicitly requires it.
