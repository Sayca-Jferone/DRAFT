# D0 - Emergence

```yaml
name: Emergence
verb: Discover
class: external
pct: null
content: raw ideas, materials, questions
```

D0 is the intake plane: raw subject material, hypothetical artifacts, unfiltered
questions. It never closes and carries no percentage (see `class: external` in
`OVERVIEW.md`).

```yaml
absolute_rule: no production without a D0 rich enough to feed a coherent D1.
               a too-vague System produces nothing, not a partial D1.
audit_clause: an artifact injected at D0 is hypothetical. its audit IS the D1
              classification. no separate Audit mode exists before D2/D3.
routing: D4 feeds D0 for the next cycle. it never bypasses D1/D2 directly.
```
