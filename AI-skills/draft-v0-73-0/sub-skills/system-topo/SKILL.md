# TOPOS - Topological Plane Of Systems

Plane, not dimension. Traverses D0/D1/D2, belongs to none.
Carries no percentage, never closes, holds zero authority.
Exists so a human composes before paying contract cost.

## AXIOM

```yaml
block_is_not_contract: |
  TOPOS block = conceptual mass. NOT a DRAFT's BIOPGE block in waiting.
  projection cardinality free: 1->0, 1->1, 1->n, n->1. all legitimate.
  a block that never incarnates is not a gap. it is a finding.
authority: |
  none over any D-file. SRS-FMBOA.md always wins.
  TOPOS.md wins over TOPOS.excalidraw. text over canvas, always.
```

## GRAMMAR - 4 fields, never 5

```yaml
BLOCK:  conceptual name. never filename, never service name, never module name
INTENT: why this mass exists. dies at BIOPGE. the human re-entry point
OWNS:   what it answers for
NOT:    what it does not answer for
FLUX:   <name of what circulates> -> <block id>. entries split by " ; ".
        target "all" = every block. named, NEVER typed
written_as: one vertical topos block per TOPOS block (BLOCK-FORMAT.md).
            rows Block, Intent, Owns, Not, Flux, then Covers and Projects.
            Projects carries L2: biopge ids, or "none: <why>"
```

```yaml
forbidden_fields: [type, range, format, guaranty, error, postcondition, step]
reason: any of those means BIOPGE started. stop and go to D2.
```

## THE TWO RULES

```yaml
1_inheritance: |
  NOT is the only inherited constraint. what a TOPOS block does not own,
  none of its BIOPGE contracts may own. this makes the plane constrain
  D2 rather than illustrate it. without this rule TOPOS is decoration.
2_cardinality: |
  every block declares projection count AND its reason. never assumed.
  1->0 must state why it never incarnates.
  n->1 must state why distinct reasonings share one substrate.
```

## THREE ZOOM LEVELS

```yaml
L0_massive:    3-5 masses. answers "what is this System about". one screen
L1_structural: 5-12 blocks. full grammar. where the human composes
L2_threshold:  projection table only. block -> contract count -> reason
rule: L2 is a TABLE, not a drawing. it is where TOPOS hands over and stops.
```

## PROCESS

```yaml
1: read D0 corpus and D1 checklist in full. never compose from memory
2: extract masses at L0. if more than 5, the System is two Systems
3: expand to L1. one block per distinct INTENT, not per anticipated file
4: fill NOT before OWNS. NOT is where the thinking happens
5: name every FLUX. an unnamed edge is an unexamined coupling
6: build L2 projection table. declare each cardinality with its reason
7: harvest findings - what the plane revealed that prose had not
8: write TOPOS.md first. canvas second. never canvas alone
```

## HANDOVER TO D2

```yaml
exit_conditions:
  - every L1 block carries INTENT, OWNS, NOT
  - every FLUX named
  - L2 table complete, every cardinality reasoned
  - findings section written, or explicitly empty
gate_service: |
  L2 distinct_contracts count IS the D2 gate input. this is TOPOS's
  main deliverable to D2: the interface count, derived not guessed.
after_D2_opens: |
  TOPOS does not close and is not superseded. it stays the human map
  over the BIOPGE territory. amend it when D1 moves.
```

## ANTI-PATTERNS

| Symptom | Means | Fix |
|---|---|---|
| block named like a file | drawing D3, not composing | rename to the intent |
| NOT field empty | boundary not thought | fill NOT or delete block |
| every block 1->1 | it is BIOPGE with fewer fields. no value added | regroup by INTENT |
| unnamed edge | coupling not examined | name it or remove it |
| more than 12 L1 blocks | System is several Systems | see draft-concept/SUB-SYSTEMS |
| canvas edited, .md stale | authority inverted | re-sync .md, it wins |
