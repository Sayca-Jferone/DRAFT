# FRAME - D0 -> D1, first

States what the System is FOR and its outline, before any rule. Every rule of
D1 descends from it (skill grain rules 3 and 5): a rule serving no FRAME claim
is decoration, a FRAME no rule can descend from is a slogan.

```yaml
output:  the head of SRS-FMBOA.md: the "> Purpose :" and
         "> Silhouette :" lines of the template
grain:   ? -> G0-G1
written: before FMBOA step 1. amended only as a D1 amendment -> PROPAGATION
read_by: FMBOA (descent check of every row), VERSION ASCENSION (the reference
         D4 evidence is compared against)
```

```yaml
purpose:     # G0, 3 lines max
  for:       one sentence, what the System is for, for whom
  like:      one analogy from the known world
  breaks:    where the analogy stops holding
silhouette:  # G1, 5 lines max. no internal name
  actors:    who uses it, who feeds it
  in:        what enters
  out:       what leaves
  flow:      the main path from in to out, one line
claims:      each sentence of purpose and silhouette is a claim, numbered
             P1.., S1.., so FMBOA rows and VERSION ASCENSION verdicts can
             name the one they serve or test
```

| Symptom | Means | Fix |
|---|---|---|
| purpose names a technology | G5 leaked into G0 | name what it is for, move the tech to an F row |
| silhouette names modules | G2 or G5 leaked into G1 | actors and flows only |
| an M row serves no claim | rule without purpose | find its claim, or question the rule |
| a claim no row descends from | slogan | write the rules, or drop the claim |
